# Admin_stat

드림몰 Admin 통계 데이터 크롤링 및 자동 전송 프로그램

사용 방법

- env 파일 생성 후 계정 정보 저장
  
  ```
  # ── 계정 정보  ──────────────────────────────────────────────────────────
  ADMIN_USER= 아이디
  ADMIN_PASS= 패스워드 
  ```

# ── 이메일 발송 설정 ──────────────────────────────────────────────────────────

EMAIL_FROM= 보내는 메일
EMAIL_PASSWORD= 앱 비밀번호          # Gmail: Google 계정 → 보안 → 앱 비밀번호 생성
EMAIL_TO= 받는 메일
EMAIL_SMTP_HOST= smtp 설정    # Naver: smtp.naver.com
EMAIL_SMTP_PORT= 포트

